HOW TO USE THIS WITH CHATGPT
============================
1. Unzip this folder first (ChatGPT makes better pictures from loose images than from a zip).
2. Start a NEW chat for each look (so the look stays the same across all the pictures).
3. Attach TWO things to your first message:
   - ALL-VIEWS-contact-sheet.jpg  (shows the whole van, so ChatGPT understands the layout)
   - one picture from the "pictures" folder, for example 1-from-the-rear-doors.jpg
4. Paste PART A, then ONE look from PART B. Send.
5. For the next picture in the same chat, attach the next picture and write:
   "Same look, same materials and colors as the last image. Now this view." (no need to paste the prompt again)
6. If something is wrong, use the fixes in PART C.
